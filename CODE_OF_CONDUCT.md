# Code of Conduct

## Our standard

We want this project to be a focused, respectful, and useful place to collaborate. Participants are expected to:

- discuss ideas and code without personal attacks;
- give specific, constructive feedback and receive it in good faith;
- respect different backgrounds, experience levels, and viewpoints;
- avoid harassment, discrimination, threats, sexualized conduct, and deliberate disruption; and
- protect private or sensitive information shared during security and support work.

These expectations apply in repository discussions, issues, pull requests, reviews, and other project spaces.

## Enforcement

Project maintainers may edit or remove contributions that violate this standard and may temporarily or permanently
restrict participation when necessary. Enforcement decisions should consider context, impact, prior behavior, and the
safety of the community.

Report conduct concerns through the repository's
[private reporting form](https://github.com/andrewsrigom/browser-extensions/security/advisories/new) and prefix the title
with `[Conduct]`. The advisory form is used only as a private intake channel for these reports; vulnerability details are
not required. Do not use a public issue when a report contains personal or sensitive information. Maintainers will handle
reports as discreetly as reasonably possible.

Good-faith disagreement about technical decisions is welcome. Harassment or retaliation against someone who reports a
concern is not.
