# Privacy Policy

Effective date: 2026-08-04

Time Zone Helper displays local and selected time zones and converts a typed time into the user's local time.

## Data Stored by the Extension

The extension stores time-zone selections, optional user-defined labels, language preference, and other display
settings in Chrome's extension-local storage (`storage.local`). These values remain on the current browser installation
and are not stored in Chrome Sync. Older popup-local settings are copied into extension storage once and removed from
the legacy location only after that copy succeeds. Typed conversion values are processed locally in the popup.

## Data Transmission and Sharing

Time Zone Helper does not send time-zone settings, labels, typed times, or any other user data to the developer or to a remote server. It does not use analytics, advertising SDKs, trackers, or third-party data processors. No user data is sold or shared.

## Data Retention and Control

Settings remain in browser extension storage until the user changes them, removes the extension, or clears extension data.

## Permission

- `storage`: saves time-zone cards and interface preferences in browser extension storage.

The extension has no content script, host permissions, or background service worker.

## Limited Use Disclosure

The use of information received from Chrome extension APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

If the extension's data practices change, this policy will be updated before a new version is published.
