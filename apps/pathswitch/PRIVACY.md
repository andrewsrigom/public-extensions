# Privacy Policy

Effective date: 2026-07-15

PathSwitch redirects matching pages to destinations configured by the user.

## Data Handled by the Extension

The extension processes top-level HTTP and HTTPS navigation URLs locally so it can compare them with the user's enabled redirect rules. It stores the enabled state, language preference, source patterns, destination URLs, rule settings, and dismissed interface tips in local browser extension storage.

PathSwitch does not build or retain a browsing-history log. A visited URL is used only for the immediate rule comparison and redirect decision.

## Data Transmission and Sharing

PathSwitch does not send visited URLs, redirect rules, settings, or browsing activity to the developer or to a remote server. It does not use analytics, advertising SDKs, trackers, or third-party data processors. No user data is sold or shared.

## Data Retention and Control

Rules and preferences remain in browser extension storage until the user edits or deletes them, removes the extension, or clears extension data.

## Permissions

- `storage`: saves redirect rules and interface preferences locally;
- `webNavigation`: observes top-level navigations so enabled rules can be matched before redirecting;
- `<all_urls>` host access: lets user-created rules work on any HTTP or HTTPS source website.

## Limited Use Disclosure

The use of information received from Chrome extension APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

If the extension's data practices change, this policy will be updated before a new version is published.
